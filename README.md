# Account Manager with Password Generator

Hi! I’m Mario, a Python student. This is a small command-line project I’m building while learning Python. It helps me practice managing account details and generating passwords.

## Features

- Add accounts with a username, email, password, purpose, and category.
- View, search, and delete saved accounts.
- Generate passwords with a chosen length and optional uppercase letters, numbers, and symbols.
- Save account information to a local text file named `data` and load it when the program starts.

## How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the folder containing the Python file.
3. Run the program, replacing `your_file.py` with the name of the script

   ```bash
   python main.py
The program uses Python’s standard library and does not require additional packages.

Important Security Note
This is a learning project, not a secure password manager. Account passwords are stored and displayed as plain text. The generated passwords use Python’s random module, which is not designed for security-sensitive password generation.

Do not use this program to store real account credentials.
